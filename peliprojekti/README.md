# Text Adventure Game

A simple console-based text adventure game written in Python. The project was created as a programming exercise to practice object-oriented programming, classes, methods, lists, loops, user input, and random generation.

## Features
* Player registration with name and age
* Age restriction for players under 12
* Interactive main menu
* Random generation of rooms and items
* Player movement between rooms
* Item collection and inventory system
* Display of the player's current location
* Random item names and values

## How It Works
When the game starts, the player enters their name and age. Players under 12 cannot enter the game.
The game then creates a number of rooms and randomly generated items. The player can use the main menu to:
* Collect an item
* View their inventory
* Move to another room
* Check their character class
* Check their current location
* Exit the game

## Technologies
* Python 3 
* random module 
* Project Structure

## The game is built using several classes:
* Game — controls the game and menu 
* Player — stores player information, movement, and inventory
* Room — represents game rooms and their items
* Item — represents collectible items
* Running the Game

**Make sure Python 3 is installed, then run:**

python game.py

### **Follow the instructions displayed in the console and enjoy exploring the rooms!**
